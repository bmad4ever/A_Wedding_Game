    ComfyUI settings
    Uses a local ComfyUI. When served with node serve.js it's reached through a built-in proxy; otherwise start ComfyUI with --enable-cors-header "*". Generating also makes the expressions the story needs (shocked, crying…) and a back-of-head view if the server has an image-edit model (Qwen-Image 2.1 or Qwen-Image-Edit). An uploaded photo can be processed the same way: cut out on a transparent background, with its own expressions and back view. No ComfyUI? No problem: the default faces (or your upload) work offline.
